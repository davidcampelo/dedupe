# security-harness knowledge-base skills

Copied unmodified from https://github.com/dmdhrumilmistry/security-harness at commit 68748d5
(`skills/sh-kb-*`), MIT licensed (see LICENSE-security-harness-MIT).

Installed: sh-kb-path-traversal, sh-kb-deserialization, sh-kb-injection, sh-kb-race-conditions,
sh-kb-secrets, sh-kb-crypto. These are plain markdown reference notes (no scripts, no hooks).

Deliberately NOT installed: sh-security-review, sh-pr-review, sh-router and the plugin agents. They
need the full plugin (shared reference files, subagents, an installer that edits the target's MCP
config and adds hooks, and a script that posts to GitHub), and overlap the built-in
/security-review and /code-review.
